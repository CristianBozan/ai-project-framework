## Como usar este backlog

- IDs são sequenciais e únicos: `BK-001`, `BK-002`, ...
- Tarefas concluídas são movidas para a seção **Concluídos** com data.
- Tarefas descartadas são movidas para **Descartados** com motivo.
- Um item pode referenciar um ADR (`[ADR-XXXX]`) ou brainstorm (`[BS-YYYY-MM-DD]`).
- A prioridade é revisada a cada sessão de revisão periódica.
